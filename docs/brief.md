# 제품 범위

SilentOrchestra는 몸짓 뒤의 실제 행동과 활성 앱을 관찰해, 사용자가 승인한 행동 연결을 기억하는 로컬 우선 Agent입니다.

## 가치

- 반복 행동에서 몸짓의 의미를 학습합니다.
- 같은 몸짓을 발표·음악 활동별로 다르게 기억합니다.
- 승인 전에는 실행하지 않습니다.
- 원본 영상과 얼굴·신원 특징을 저장하지 않습니다.
- 학습된 기억과 신뢰도를 UI에 표시합니다.

## 현재 범위

Windows 실기 경로는 활성 앱과 실제 후속 키를 관측합니다. 웹 UI와 라벨 모드는 같은 루프를 시뮬레이션합니다. 카메라는 `swipe:right/left`, `open_palm:none`, `circle:clockwise`를 지원합니다.

현재 구현은 고정 모션 특징과 최근 행동 통계를 사용합니다. 활동은 발표·음악 두 개이고, 몸짓·활동당 활성 Intent는 하나입니다. 연속 문법·자유 몸짓·신원 학습은 지원하지 않으며 초기 반복과 승인이 필요합니다.

요구사항은 [SPEC](../spec.md), 실행 한계는 [PLAN](../plan.md)가 소유합니다.
