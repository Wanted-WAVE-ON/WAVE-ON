# 3분 데모 대본

## 준비

[README](../README.md#시작하기)대로 실행하고 `Reset demo` 후 Presentation을 선택합니다. OS 실행은 끕니다. 기본 흐름은 버튼·라벨 시뮬레이션임을 먼저 밝힙니다.

## 순서

1. **0:00–0:25** — “몸짓 뒤의 반복 행동을 활동별로 기억합니다. 지금은 학습 루프 시뮬레이션입니다.”
2. **0:25–1:10** — 오른쪽 손짓과 다음 슬라이드를 3회 연결합니다. 승인 전 자동 실행이 없음을 보여줍니다.
3. **1:10–1:35** — 제안을 승인합니다. “승인된 연결만 Personal Gesture Memory가 됩니다.”
4. **1:35–1:55** — 오른쪽 손짓을 다시 보내 Intent와 confidence 오버레이를 보여줍니다.
5. **1:55–2:30** — Music에서 같은 몸짓을 다음 트랙과 연결·승인해 맥락 분기를 보여줍니다.
6. **2:30–2:50** — 실행 결과에 맞음/틀림 피드백을 남깁니다.
7. **2:50–3:00** — “원본 프레임은 저장·업로드하지 않습니다.”

Windows 실기 경로는 활성 앱과 실제 후속 키를 관측합니다. 초기 반복·승인은 여전히 필요하며, 단일 관례적 매핑만으로 개인화 성능을 주장하지 않습니다.

## 실패 대응

| 문제 | 대응 |
|---|---|
| 웹캠 | 버튼 시뮬레이션 사용 |
| OS 실행 | `DRY_RUN` 오버레이 사용 |
| 학습 데이터 | Reset 후 Presentation만 재시연 |
| 시간 부족 | Music은 Memory 화면으로 설명 |
