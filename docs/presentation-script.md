# 발표 슬라이드별 핵심 멘트

1. **표지** - “AI에게 제스처를 가르치는 것이 아니라, AI가 나의 몸짓 언어를 배웁니다.”
2. **문제** - 고정 제스처는 외워야 하고, 맥락이 바뀌어도 의미가 고정됩니다.
3. **해결** - Observation, Context, History로 Intent를 추론합니다.
4. **핵심 경험** - 세 번의 자연스러운 반복 후 Agent가 먼저 기억을 제안합니다.
5. **상황 추론** - 같은 몸짓도 Presentation과 Music에서 다른 행동입니다.
6. **아키텍처** - 원본 프레임을 폐기한 뒤 특징 벡터부터 저장합니다.
7. **DB/ERD** - gesture-command 매핑이 아닌 학습 이력 중심의 스키마입니다.
8. **Privacy** - 영상과 얼굴을 저장하지 않는 구조적 안전장치입니다.
9. **MVP** - FastAPI, SQLite, Web UI, OpenCV 선택 기능까지 실행 가능합니다.
10. **검증** - Pytest 16개 테스트와 SQLite 38개 문장을 통과했습니다.
11. **확장** - IoT, 접근성, 스마트홈으로 연결할 수 있습니다.
12. **마무리** - 사용자가 적응하는 인터페이스에서 사용자에게 적응하는 인터페이스로 전환합니다.
